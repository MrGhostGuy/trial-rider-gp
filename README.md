# Trial Rider GP

An original 2D physics motorcycle trials game in a single HTML file.
Ride a dirt bike across hills, rollers, a big kicker jump and whoops to the
finish arch. Lean to keep your balance — land on your head and it's a fault,
and you're back at the last checkpoint with the clock still running.

**Controls**
- W / ↑ / Space — gas
- S / ↓ — brake / reverse
- A,D / ←,→ — lean back / forward
- R — reset to checkpoint (counts as a fault)
- On-screen buttons work with mouse or touch.

5 checkpoints, finish timer, fault counter, best time for the session.
